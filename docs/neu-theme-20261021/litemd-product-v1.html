产品定位与边界

POSITIONING & SCOPE

一句话：LiteMD 是本地优先的轻量 Markdown 写作器——打开文件夹就能写，实时预览、导出、同步，其余一切从简。所有功能取舍以此判据裁定。

做（本方案范围）

主题素塑亮（白，主形态）+ 素塑暗（对偶，本期交付）
同步WebDAV（现状已有，保持）

不做（边界，已确认）

移动端目标平台 x86 Windows/Linux + ARM Linux 桌面端

单一数据源：菜单注册表

MENU REGISTRY · SINGLE SOURCE

P0-5 的根治方案：把现有 ALL_ACTIONS（快捷键注册表）升级为菜单注册表，菜单栏、命令面板、右键菜单、设置页全部从同一份数据渲染。新增功能只改注册表一处，杜绝两处维护。

注册表条目结构（拟 TypeScript）

interface MenuItem {
  id: string;        // 'file.save' —— 与 ALL_ACTIONS 对齐
  label: string;     // '保存'
  group: MenuGroup;  // file | edit | view | insert | format | tool | window | help
  accel?: string;    // 'Ctrl+S'，空则不出现在快捷键列
  scope: 'app' | 'editor';
  icon?: string;     // 图标 symbol id
  when?: () => boolean; // 禁用态谓词（无打开文件时灰化）
  run: () => void;     // 唯一执行体
  menus: 'bar'[];      // 出现在哪些入口：bar/palette/ctxEditor/ctxTree/ctxTab
}

四个消费方（全部只读注册表）

菜单栏按 group 分 8 组渲染，accel 右对齐，when() 驱动灰化
命令面板模糊匹配 label + id，三类源（命令 / 文件 / 设置）同列表分组展示
右键菜单按 menus 字段过滤出四套上下文集
设置-快捷键现有页改为注册表驱动：改键即改 shortcuts[id]，菜单与面板同步生效
迁移策略：现有 SHORTCUT_GROUPS / DEFAULT_SHORTCUTS / ALL_ACTIONS（settings.ts:132-249）结构已接近目标形态，扩展 group/menus/icon/run 四字段即可，存量快捷键配置零迁移成本。

18.1 MVP 通道：最小可产品化子集

「无法产品化」的病根是功能不可发现（菜单残废 + 无命令面板 + 无大纲）。因此 MVP = B1 + B2 + B3 + B4 四批：换肤 + 菜单体系 + 命令面板 + 大纲/视图切换。这四批落地后，LiteMD 具备「用户能自己找到所有功能」的最低产品形态；B5–B7 是渲染补强与收口，可排后续迭代。

K5 · 大纲标题抽取（B4，100KB < 2ms）

// outline.ts —— 单次线性扫描，不建 AST、不依赖 markdown-it
export interface OutlineItem { level: 1|2|3|4|5|6; text: string; line: number; }

export function extractOutline(doc: string, maxLines = 2000, max = 500): OutlineItem[] {
  const out: OutlineItem[] = [];
  let inFence = false, fenceChar = "";
  const lines = doc.split("\n", maxLines);
  for (let i = 0; i < lines.length && out.length < max; i++) {
    const ln = lines[i];
    const fence = ln.match(/^\s*(`{3,}|~{3,})/);           // 围栏开关（``` 与 ~~~ 都要）
    if (fence) { if (!inFence) { inFence = true; fenceChar = fence[1][0]; } else if (ln.trimStart().startsWith(fenceChar.repeat(3))) inFence = false; continue; }
    if (inFence) continue;
    const atx = ln.match(/^(#{1,6})\s+(.+?)\s*#*$/);        // ATX 标题；围栏内已排除
    if (atx) { out.push({ level: atx[1].length as 1, text: atx[2], line: i }); continue; }
    const setext = ln.match(/^(=+|-+)\s*$/);                 // setext：看上一行非空文本
    if (setext && i > 0 && lines[i-1].trim() && !/^\s*$/.test(lines[i-1])) {
      out.push({ level: setext[1][0] === "=" ? 1 : 2, text: lines[i-1].trim(), line: i - 1 });
    }
  }
  return out;
}
