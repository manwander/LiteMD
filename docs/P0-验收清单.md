## A. 启动与基础浏览

- [ ] A1. 启动后窗口出现「LiteMD」标题、1280×800 尺寸、文件 / 编辑 / 视图 / 设置 工具栏按钮可点
- [ ] A2. 三栏布局正常：左侧文件区（提示文字）、中间 CodeMirror 编辑器、右侧实时预览
- [ ] A3. 内置欢迎文档 `# 欢迎使用 LiteMD` 渲染正确（预览区看到 H1 / 列表 / 引用 / 代码块）
- [ ] A4. 工具栏按钮可点（B / I / U / 删除线 / 标题 / 列表 / 引用 / 链接 / 主题切换）

## B. 文件操作

- [ ] B1. **打开文件**：`文件 ▾ → 打开文件` 或 `Ctrl+O`，选一个 .md，编辑器加载内容，状态栏显示「已打开 xxx.md」
- [ ] B2. **打开文件夹**：`Ctrl+Shift+O`，选一个含 .md 的目录，左侧文件树出现一级文件夹 → 文件列表
- [ ] B3. **文件树点击**：在左侧点一个文件，编辑器加载、文件名高亮
- [ ] B4. **保存**：`Ctrl+S`（当前未保存过会自动触发「另存为」），选路径后写盘
- [ ] B5. **另存为**：`Ctrl+Shift+S`，选路径，文件写入
- [ ] B6. **导出 HTML**：`Ctrl+E`，选 .html 路径，浏览器打开能看到完整样式（标题、列表、引用、代码块、链接颜色 #0F6E56）
- [ ] B7. **修改文件**：编辑后等 0.8 秒，状态栏显示「已自动保存」，磁盘文件已更新

## C. 快捷键（默认）

- [ ] C1. 编辑器内 `Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+U` 下划线
- [ ] C2. `Alt+Shift+5` 删除线
- [ ] C3. `Ctrl+K` 插入链接（选中文本 → 链接文字，未选 → "链接文字"）
- [ ] C4. 编辑器内 `Ctrl+F` 打开搜索面板，`Ctrl+H` 打开替换面板，`Esc` 关闭

## D. 设置持久化

- [ ] D1. 切换主题到深色 → 立即生效（编辑器 + 预览 + UI）
- [ ] D2. 调字号到 18px → 编辑器内文字变大
- [ ] D3. 关闭应用、重启 → 主题 / 字号 / 上次打开的文件夹 / 上次打开的文件 **全部恢复**
- [ ] D4. 设置文件位置：Windows `%APPDATA%\com.litemd.app\settings.json`（可在「通用 → 配置文件」标签页看到完整路径）
- [ ] D5. 配置文件是合法 JSON，结构对应 `Settings` 接口

## E. 快捷键设置面板（与 spec 对齐）

- [ ] E1. 菜单 → 设置 或工具栏 ⚙，弹出 900×640 面板，左侧导航含「通用 / 编辑器 / 外观 / 快捷键 / 导出 / 关于」
- [ ] E2. 「快捷键」标签页：4 组（文件 / 编辑 / 格式 / 视图），每行「操作名 + 键位药丸」
- [ ] E3. **重绑定**：点一个药丸 → 文字变「按下组合键…」→ 按下 `Ctrl+Shift+L` → 药丸立刻显示「Ctrl + Shift + L」且立即生效
- [ ] E4. **冲突检测**：尝试把另一个键位绑到 `Ctrl+Shift+L`，底部消息「Ctrl + Shift + L 已被「xxx」占用」
- [ ] E5. **Esc 取消**：重绑定过程中按 Esc → 回到原键位
- [ ] E6. **单条恢复**：某键位右侧 ↺ 按钮变可点（原本是默认时灰），点击 → 恢复默认
- [ ] E7. **全部恢复**：底部「恢复默认」→ 所有键位回到出厂值
- [ ] E8. 「通用」标签页：自动保存开关、自动保存延迟滑杆（300~3000ms）、默认目录、配置文件路径展示
- [ ] E9. 「外观」标签页：浅色 / 深色 chip 切换
- [ ] E10. 「编辑器」标签页：字号 +/− / 数字药丸、「启动时展开目录 / 预览」开关
- [ ] E11. 「关于」标签页：版本号、技术栈、配置文件路径

## 附录：手动启动方式（开发模式）

```bash

$env:PATH = "$env:USERPROFILE\.cargo\bin;$env:PATH"
cd C:\Users\manwa\Desktop\LiteMD
npm install                 # 首次
npm run tauri dev           # 开发模式（热更新）
# 或
npm run tauri build         # 生产构建（出 .exe / 安装包到 src-tauri\target\release\）
```
