## 📝 2-4 上传 TOCTOU：读↔stat 非原子可永久丢编辑（报告 1-B / 严重，清单#5）
- **定位**：`src-tauri/src/sync/engine.rs` `do_upload`（804-845）与 `do_conflict` KeepBoth（906/960）。
- **原因**：`read_bytes`(811) 与 `stat_of`(813) 之间被再次保存 → 落快照「v1 哈希 + v2 元数据」→ 下轮 size+mtime 相等判未变（229-230）→ v2 永不上传。
- **建议改法**（读前读后各 stat 一次，抖动则重读重试，稳定后以读到字节与同刻元数据一并入快照）：
```rust
async fn do_upload<T: Transport>(t:&T, root:&Path, snap:&tokio::sync::Mutex<Snapshot>, item:&PlanItem, force:bool) -> Result<Vec<OutcomeTag>,String> {
    // 消除 TOCTOU：stat→read→再 stat，两次一致才认；不一致重读（最多 3 次）
    let (mut size, mut mtime) = stat_of(root, &item.rel).await?;
    let bytes; let hash; let mut settled=false;
    for _ in 0..3 {
        let b = read_bytes(root.join(slash(&item.rel))).await?;
        let (s2,m2) = stat_of(root,&item.rel).await?;
        if s2==size && m2==mtime { bytes=b; hash=sha256_bytes(&bytes); settled=true; break; }
        size=s2; mtime=m2;
    }
    if !settled { bytes = read_bytes(root.join(slash(&item.rel))).await?; hash=sha256_bytes(&bytes); }
    // ↓ 其余（force 分支、哈希一致短路、upload、upsert 用 size/mtime/hash）保持原逻辑，
    //   仅把原先 813 行的 st 换成上面稳定后的 (size,mtime)，834-837 用 hash/size/mtime
    // ...
}
```
- **潜在影响**：多 1-2 次 `stat`（本地 fs，廉价）；极端持续写入时退化为「以最后一次读为准」，仍优于现状的永久丢编辑。`do_conflict` 906/960 需同样改造（读取与 stat 成对原子）。
- **验证方式**：`cargo test`（`conflict_keep_both_produces_copy_and_converges` 等）；补单测模拟「读后 stat 前改内容」需 mock 文件系统时序，成本较高——建议手测：大文件同步中连续保存 3 次，观察下一轮是否补齐上传。
- **待确认**：是否接受多次 stat 的成本；`do_conflict` 一并改。

```ts
function parseFence(doc:FenceDoc, ln:number): {ch:number,len:number}|null {
  const line=doc.line(ln); const to=Math.min(line.to, line.from+FENCE_SCAN);
  const s=doc.sliceString(line.from,to); let i=0,sp=0;
  while(i<s.length && (s.charCodeAt(i)===32||s.charCodeAt(i)===9)){sp++;i++;}
  if(sp>3) return null;                       // ≥4 空格缩进属代码内容，非围栏
  const c=s.charCodeAt(i); if(c!==96 && c!==126) return null; // 只认 ` 与 ~
  let n=0; while(i<s.length && s.charCodeAt(i)===c){n++;i++;}
  if(n<3) return null;
  return {ch:c,len:n};
}
function isCloseFence(doc:FenceDoc, ln:number, open:{ch:number,len:number}): boolean {
  const f=parseFence(doc,ln); if(!f || f.ch!==open.ch || f.len<open.len) return false;
  // 闭栏标记之后只允许空白
  const line=doc.line(ln); const rest=doc.sliceString(line.from,line.to);
  const after=rest.slice(rest.indexOf(String.fromCharCode(f.ch))+f.len);
  return after.trim().length===0;
}
```
